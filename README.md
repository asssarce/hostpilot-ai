# HostPilot AI

AI infrastructure for modern hotels and hostels.

## Foundation

- Next.js App Router + TypeScript
- Prisma + PostgreSQL
- Guest knowledge and Q&A foundation
- Pricing rules foundation
- Local recommendation capability planned
- Docker-ready project structure

## Product direction

HostPilot AI is designed around three high-value workflows:

1. **Guest AI** — reliable answers grounded in property-specific knowledge.
2. **Revenue intelligence** — pricing recommendations based on demand, occupancy, events, and booking lead time.
3. **Local intelligence** — context-aware recommendations for places, events, nightlife, and activities.

See `docs/` for architecture and implementation decisions.

## Development

Use Node.js 22+, install dependencies, configure `DATABASE_URL`, then run the Next.js development server.
